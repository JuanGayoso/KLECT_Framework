# Modo `/retroalimentar [lección o ID]`

**Propósito:** cerrar el ciclo de aprendizaje llevando una lección hacia atrás, a la revisión de diseño de proyectos nuevos (backward-flow).
**Salida:** alerta KLECT-BACKWARD → ítem de checklist → justificación.

## Procedimiento
1. Verificar elegibilidad: CAT-1/2/3 **o** severidad Alta/Crítica. Si no lo es, explicarlo y ofrecer un ítem opcional.
2. Redactar el ítem: imperativo, verificable sí/no, máx. 2 líneas.
3. Fijar la fase de verificación en el nuevo proyecto (normalmente la fase de **origen** de la causa, no la de detección).
4. Asignar riesgo 🔴/🟠/🟡 con criterio explícito.
5. Justificar en 2–3 frases con trazabilidad al ID de la lección.

## Formato
```
KLECT-BACKWARD · <ID> · <fecha>
Alerta: ...
Item checklist: "..."
Fase de verificación: ...
Nivel de riesgo: 🔴/🟠/🟡
Justificación: ...
```
